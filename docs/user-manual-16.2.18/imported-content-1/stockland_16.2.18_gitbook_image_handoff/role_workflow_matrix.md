## Gaps by role

* **Owner/Management:** Saved user creation result, existing-account role/location reassignment result, live System Health Quick/Deep results, live System Control state/fingerprint, Business Calendar.
* **Branch Manager:** Validated count workbook, variance, final approval result; POS staged file reconciliation and actual release/post result; actual return/adjustment approval/ledger; completed daily close.
* **Sales Employee:** Genuine populated POS cart and successful posting/reference; actual Daily POS upload, validation, staged job and duplicate-safe outcome.
* **Warehouse roles:** Approved requisition detail, reservation/pick/handover, PO line receipt, transfer dispatch and destination receipt/completion.
* **Auditor:** Report filter/output/print result and actual audit record detail.
* **HR/Payroll:** Genuine lifecycle gate and SOP library preview only; no fictional payroll calculation or payslip.
