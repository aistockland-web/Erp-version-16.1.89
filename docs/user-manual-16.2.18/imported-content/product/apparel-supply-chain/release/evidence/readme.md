# README

This folder holds static source/workspace validation receipts only. It is not a certificate, external audit opinion, software bill of materials for a production release, or deployment receipt.

* `SCHEMA_TEST_RESULTS.md` mirrors the final static registry test result.
* `WORKSPACE_VALIDATION.txt` records file counts, schema checks, CSS non-change, GitHub write limitation, and no-runtime/no-deployment state.

All checks must be repeated after any file changes because the SHA-256 manifest is regenerated from exact bytes.
