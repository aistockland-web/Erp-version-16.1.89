## Candidate feature

Adds an HR Process Center document catalogue with Function, Role, Language, Document Type and Search filters; permits downloads of 30 bundled DOCX resources; checks server-side role permission, allow-listed path, file length and SHA-256; writes `HR_RESOURCE_DOWNLOAD` to the existing audit chain before returning document bytes. Resource downloads reuse the existing `Stockland_Authority::can_view_hr()` policy (Owner/Management); introducing a distinct HR employee role is not part of this candidate.

No existing payroll formulas, GL/PLEDGER posting, current employee records, current HR tables or business data are changed. Existing database and HR schema version markers are preserved. This is not a full HR/payroll replacement.
